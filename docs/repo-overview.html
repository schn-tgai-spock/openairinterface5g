OpenAirInterface 5G RAN repository overview

A native LTE and 5G radio access network stack for eNB, gNB, UE, split RAN, simulated radio, hardware radio, and fronthaul experiments. The codebase is organized by RAN layers and runtime roles, not by web application tiers.

Where To Start

To run a node: start in executables/ and the example configs under targets/ or ci-scripts/conf_files/.

To understand protocol behavior: follow the layer ownership from openair1/, openair2/, and openair3/, then use ITTI task names to trace runtime interaction.

To verify changes: use CMake and CTest paths. PHY work usually needs physim coverage; RRC/NAS/rfsim behavior often needs CI-scripted scenarios.

Build graph

CMake owns the build graph; helper scripts exist, but direct CMake/Ninja is the normal developer path.

Runtime shape

Softmodem binaries assemble reusable protocol, runtime, radio, and split-mode libraries at startup.

Scale

The codebase is large enough that directory and flow maps are a prerequisite to productive source reading.

Top-Level Directory Map

executables/

gNB, UE, CU, DU, and softmodem entry points.

openair1/

PHY layer processing, simulation paths, and low-level signal work.

openair2/

MAC, RLC, PDCP, SDAP, RRC, and layer-2 control logic.

openair3/

NAS and core-facing protocol implementations such as NGAP and GTP.

common/

Shared utilities, configuration, logging, ITTI support, and platform code.

nfapi/

FAPI/nFAPI support for PNF/VNF-style split integrations.

radio/

Radio backends including hardware and simulated radio paths.

fronthaul/

Native and O-RAN-oriented fronthaul split support.

targets/

Example runtime configurations and project-specific target files.

ci-scripts/

End-to-end scenario harnesses, configs, and CI execution scripts.

docker/

Build and runtime container images used by CI and deployment flows.

tests/

Standalone tests and validation programs outside the main runtime tree.

cmake_targets/

Build helper scripts, dependency install helpers, and physim lists.

doc/

Contributor, tutorial, feature, and code-style documentation.

tools/

Formatting, static analysis, and developer support utilities.

charts/ openshift/

Kubernetes and OpenShift packaging for CI and deployment contexts.
